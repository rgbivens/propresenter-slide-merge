Slide Merge

Turn one ProPresenter slide and a spreadsheet into a set of presentations, one per row, ready to drop into your library.

1. Build one slide

In ProPresenter, design a slide the way every copy should look. Type placeholder text into each box you want filled in, such as “Name” and “Title.”

2. Get your list ready

Put one person or item per row in a spreadsheet, with column names in the first row, such as First Name, Last Name and Title.

3. Merge and import

Work through steps 1 to 4 below, download the zip, then drag the files onto a library in ProPresenter. The example below shows how it works.

Step by step

  1. Find your template file. Each ProPresenter presentation is saved as a .pro file. On a Mac, libraries are in ~/Library/Application Support/RenewedVision/ProPresenter/UserWorkspaces/ProPresenter/Libraries, one folder per library. In Finder, choose Go › Go to Folder and paste that path. Drop the file on step 1.
  2. Add your list. Copy the cells from Excel, Numbers or Google Sheets and paste them into step 2, or upload a CSV. Leave “First row is column names” checked if your first row has headings.
  3. Fill each text box. In step 3, click a column button to add it to a box. You can combine columns and add words, for example {First Name} {Last Name} or Pastor {Last Name}. Leave a box empty to keep the template text on every slide, or check “Leave this box blank” to clear it.
  4. Name the presentations. Step 4 sets each file name the same way, for example Fall Retreat - {Last Name}. Duplicate names get a number added.
  5. Check the list. Click any row to preview it, then use the ↑ and ↓ keys or the arrows above the preview to page through. Rows marked “Check fit” may run outside their box; the red outline shows which one.
  6. Download and import. Unzip the download, then drag the .pro files onto a library in ProPresenter’s sidebar. Open a few to check them before you use them live.

Questions

Is my list uploaded anywhere?

No. The page reads your template and list in your browser and builds the files there. When you download, it sends one anonymous count to this site: the date and how many presentations you made. Your names, columns and files are never sent.

Why can’t I change one of the text boxes?

The box uses more than one style inside its text, such as a bold word in a plain sentence. Slide Merge leaves those boxes as they are. Give the box a single style in ProPresenter and choose the template again.

The background is missing after I import.

Presentations point to their images and videos by where they’re stored on the computer that made them. Import on that computer, or make sure the same media is in ProPresenter on the computer you import to.

A name runs outside its box.

Fit warnings are estimates, because this page can’t use your slide’s exact fonts. Shorten the text in your list, or adjust that slide in ProPresenter after importing. Adding your background image to the preview makes it easier to judge.

Can I upload an Excel file?

Not directly. Copy the cells and paste them into step 2, or save the sheet as CSV first.

Which versions of ProPresenter work?

Slide Merge has been tested with ProPresenter 21.4 on a Mac. Other versions may work, but ProPresenter’s file format isn’t published and could change in an update. Try one file before importing a large batch, and back up your library first.
